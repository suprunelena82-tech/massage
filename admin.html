Де взяти токен? Покрокова інструкція
  1. Зайдіть на github.com під своїм акаунтом.
  2. Натисніть на аватар → Settings → унизу ліворуч Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Назва: Керування сайтом. Термін дії: оберіть найдовший (до 1 року).
  4. Repository access → Only select repositories → оберіть репозиторій із сайтом.
  5. Permissions → Repository permissions → знайдіть Contents і виберіть Read and write.
  6. Натисніть Generate token, скопіюйте ключ (починається з github_pat_) і вставте у поле вище. Після закриття сторінки GitHub не покаже його знову.
Не хочу використовувати токен

Можна внести зміни тут, завантажити готовий файл config.json і вручну замінити ним старий файл у репозиторії (GitHub → Add file → Upload files). Фото в цьому режимі змінити не можна.
